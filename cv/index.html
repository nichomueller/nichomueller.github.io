PhD Researcher, Monash University

Reduced-order methods and scientific software for parameterised PDEs, aimed at problems large enough that full-order simulation becomes computationally impractical.

  • Built modern methods addressing the challenges posed by large-scale space-time problems, or ones defined on moving geometries.
  • Authored GridapROMs.jl, an open-source Julia library for reduced-order modelling; its algorithms have achieved massive speedups over full-order simulations.

GridapROMs.jl

A Julia package for reduced-order modeling of parameterized PDEs — steady or transient, linear or nonlinear, single- or multi-field.

  • POD, Tucker, tensor-train, interpolation, and localized subspace strategies, all behind the same interface.
  • Distributed-memory snapshot generation, because the offline stage is usually the bottleneck.
  • A high-level API I've kept readable on purpose, even as the internals got more complicated.

Opals.jl

A Julia package for data assimilation and inverse modelling. It replaces MeteoModels.jl, an earlier package of mine that's no longer maintained — same idea, sequential filters and variational estimators behind one interface, rebuilt with a design I actually trust.

  • Kalman, extended/unscented Kalman, ensemble Kalman, and particle filters, plus 3D-/4D-Var, all sharing the same execution and diagnostics.
  • Things like covariance localization/inflation, adaptive noise estimation, and bias-aware correction are wrappers around a common filter interface, so you compose what you need instead of picking a monolithic implementation off a shelf.
  • A reservoir-computing (echo state network) module I wrote from scratch for the bias correction, which turned out more accurate and cheaper to train than ReservoirComputing.jl on the benchmarks I ran.
  • Talks natively to SciML for ODEs and to Gridap/GridapROMs for full- and reduced-order PDE models, so a reduced-order surrogate can drop in for a full-order solver without touching the assimilation code.

How I design software

  • An interface should expose the underlying math, not hide it behind abstraction for its own sake.
  • If I can't measure a performance claim, I don't trust it, so profiling and benchmarking happen as I go, not after.
  • Environment management, tested examples, documented workflows — boring, and the reason a collaborator doesn't have to email me to get something running.
  • A package should work equally well for someone prototyping a new method and someone bolting it into a bigger pipeline.
